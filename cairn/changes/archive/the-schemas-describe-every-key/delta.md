## MODIFIED Requirements

### Requirement: The JSON contract is described and versioned
A command printing one of two shapes SHALL be described by both, each alternative saying when it prints. Every key a schema lists SHALL carry a description, written in JSON terms (`null`, never a Rust `None` nor an intra-doc link), and a value from a closed set Himalaya defines (`sieve raw` `status`, `pimdir performer` `capability`) SHALL be listed as an `enum`; a set the store or the server may extend (a queue row's `kind`, a mailbox `role`) stays a string.
