# The API is unified

The cross-protocol API is called the unified API, its commands, verbs, leaves, capabilities, writes, operations and outputs following, in the code, the `--help` text, the docs and the spec; no behaviour changed. Capabilities moved: commands (requirements renamed "Unified commands over a resolved transport", "The unified command tree is the same in every build", "Unified mailbox writes", "The important and junk flags are in the unified API", "The auto-reply is in the unified API"), backends ("Unified operation set", "Unified outputs carry no backend details"), mcp ("Tools are the classified unified API").
