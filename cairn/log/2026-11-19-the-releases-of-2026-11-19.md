# The releases of 2026-11-19

## What landed

- Cargo.toml: io-imap 0.12.0 (`std` in place of `client`), io-smtp 0.10 (`std` asked), io-sasl 0.3, io-managesieve 0.5, io-pimdir 0.18.0, pimalaya-cli 0.7.0 (build dependency too). One io-sasl in `cargo tree`.
- HIM-18, src/imap/raw.rs: `split_reply` takes io-imap's `Vec<Vec<u8>>`, a UTF-8 response parsed as before, another printed as `ImapRawEvent::Undecoded { base64 }`; `split_responses`, `literal_size` and the `unframed` fallback removed; a tagged response that is not UTF-8 sets `unread` and exits 3. The `himalaya-imap-raw.events` schema gains the `undecoded` alternative (derived). Tests `an_8bit_literal_prints_its_exact_octets` and `a_literal_line_spelling_a_completion_stays_in_its_literal` failed against the lossy reading (the old splitter behind the new signature) before the new splitter; `an_8bit_completion_is_left_unread` added.
- C5, src/pimdir: `is_mail` removed for `collection::media_type`; `resolve_account` on `PimdirReader::accounts_of`, accepting a configured account on an empty store (test `a_configured_account_is_read_on_an_empty_store` in tests/pimdir_refusals.rs, failing on the old rule with `store-account-unknown`); `scope` on `PimdirQuery::scoped`; `PimdirMailCoverage` drops `reads`, `reads_mark` and `reads_content` for `counted`, `unread_counted()`, the JSON counts unchanged; `overlay_quiet` removed, its tests kept against `PimdirReader::overlay_quiet`.
- pimalaya-cli 0.7: `api_url` refuses through `error::request_origin`; `gmail request` and `msgraph request` drop their clap `path_parser` for a `check` the dispatcher runs before the session, as `smtp send`'s; `a_url_off_the_api_is_refused` asserts `CommonCode::RequestOrigin` and `a_request_off_its_api_is_refused_before_the_session` (tests/early_refusal.rs) exit 1 and the code, a token command `false` proving no session opened; both failed first. `attachment download`'s `sanitize` calls `sanitize::path_component`, its local `BIDI` list gone.
- CHANGELOG (dependencies, `imap raw` breaking, the `request` and account lines amended), MIGRATION (v2 to v3 and development build lines).

## Not done

- C6, a code on an IMAP refusal through `ImapStatusError::code_bytes`: ruled after v3.
