# The live campaign fixes

The fixes of the 2026-11-12 live campaign against the Fastmail (IMAP, SMTP, JMAP), iCloud, Gmail and Microsoft Graph test accounts and the local stores landed, Microsoft Graph's own batch excepted, which folds on its own. The id-taking writes act on what the mailbox given holds and count it (ids required and deduplicated, scoped on JMAP and Gmail, looked up before the first write on Maildir, m2dir and mbox, a trash removal counted, a JMAP trash removal no longer destroying an email other mailboxes hold); IMAP reads the special-use roles a plain `LIST` carries and resolves role words through them, imap-special-use-aliases staying active for `RETURN (SPECIAL-USE)`; iCloud sorts client-side; the search grammar is strict and reports once; mailbox writes validate NAME and print full names; flag options take one value per occurrence; the composers, Gmail, JMAP, IMAP, Maildir, m2dir and mbox gaps the campaign found are closed.

Capabilities moved: provider-quirks ("IMAP special-use is inbox-only for now" renamed "IMAP special-use roles come from a plain LIST" and rewritten, "iCloud SORT ignores its keys" added), commands ("An unserved verb is refused before connecting", "Raw passthrough is byte-verbatim", "account check covers every declared backend", "Text output is plain text", "Data commands serialize their data", "Composers default the From header", "Raw message input is shared", "Saving a sent message follows the send", "A sent reply or forward flags its source", "A forward carries the attachments of its source", "A read message is a designed view", "A part can be read without touching the disk", "A command given message ids says how many it found", "Unified mailbox writes", "The auto-reply is in the unified API", "A write prints what it acted on", "Listings resume from their cursor", "An IMAP command prints its completion"), backends ("JMAP writes are scoped to the mailbox given", "A JMAP duplicate import files the existing email" and "A Gmail answer joins its parent's thread" added; "IMAP flag counts", "Local storage backends", "mbox backend", "An mbox message is its content id", "Maildir surfaces custom keywords on demand", "Mailbox role" modified), search ("One query language", "A query that does not parse is refused with a code", "What a backend searches is declared", "Per-backend translation"), mcp ("A tool's input is the command's grammar", "A tool reads and writes no local file", "An attachment is read as an embedded resource").

Library fixes ride on path patches in Cargo.toml, each uncommitted in its repository and needing a release before its patch goes: io-maildir (flags in ASCII order, a store listing skipping plain files, `copy` returning the new id), io-jmap (`alreadyExists` with its `existingId`, `Other` errors keeping type and description, query order, `newState: null`), io-imap (RFC 5256 client-side sort, LIST and LSUB patterns in modified UTF-7 and quoted), io-gmail (path segments percent-encoded), mime-rs (an attached message never base64, no boundary shared with an attached message) and pimalaya-cli (the-tree-gets-its-pages: a manual page per command, MCP lone values and integers, re-pinned by git rev once committed).
